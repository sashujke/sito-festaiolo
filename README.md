# Il Festaiolo

Sito web statico per **Il Festaiolo**, realizzato con HTML, CSS e JavaScript vanilla.

## Avvio locale

Dalla cartella del progetto:

```bash
python3 -m http.server 8000
```

Apri <http://localhost:8000>.

## Pubblicazione

Il progetto è pubblicato su GitHub:

<https://github.com/sashujke/sito-festaiolo>
